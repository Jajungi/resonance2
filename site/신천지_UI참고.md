## 2. 홈 레이아웃 (위에서 아래)

1. **헤더** — 흰 배경, 높이 약 50px, 모서리 없음. 로고 왼쪽 / 메뉴·검색·언어 오른쪽  
2. **히어로 캐러셀** — **풀블리드에 가깝고 모서리 거의 직각**. 슬라이드마다 **다른** 전용 비주얼(사진 또는 일러스트). 좌우 화살 + 하단 도트  
3. **파란 CTA 바** — 둥글기 **약 12px** 정도만. 좌 카피 + 우 재생 버튼  
4. **아이콘 퀵메뉴** — 흰 사각, 테두리 얇음, 둥글기 **약 6px**. **사진 없음**, 라인 아이콘 + 짧은 라벨  
5. **인기영상 / 공식채널** — 썸네일·카드로 가독성 (여기부터 이미지가 “콘텐츠”로 등장)  
6. **푸터** — 로고·약관·문의·전화. 여백 넉넉, 장식 최소

핵심: **히어로·영상·행사사진에만 이미지가 집중**. 퀵메뉴·본문 리스트는 아이콘/활자.

---

## 3. 모양 · 둥글기 (실측 감각)

| 요소 | 관찰 |
|------|------|
| 페이지/헤더/히어로 프레임 | **0px에 가까움** (직각) |
| CTA 바 | **~12px** |
| 퀵 아이콘 카드 | **~6px** |
| 원형 | 재생 버튼·도트 등 **기능 요소만** |
| 그림자 | 아주 옅음. 카드마다 두껍게 쌓지 않음 |

→ 우리 사이트의 `1.5rem`·`999px` 남발은 신천지보다 **훨씬 AI/앱 카드** 쪽.

---

## 4. 이미지로 가독성 챙기는 곳

| 위치 | 쓰임 |
|------|------|
| 히어로 슬라이드 | 슬라이드마다 **고유** 비주얼. 같은 컷 반복 없음 |
| CTA | 색 면 + 아이콘 (사진 아님) |
| 퀵메뉴 | **아이콘만** |
| 영상·행사사진·수료식 | 썸네일 그리드 (여기가 사진 본진) |
| 내페이지 본문 | 긴 텍스트 + 소제목. 사진 남발보다 **글 밀도** |

내페이지(연혁 등): 상단 타이틀 바 → 서브내비 → 연도/항목 **리스트·장문**.  
사진 없이도 읽히게 타이포·구분선·연도 숫자로 리듬.

---

## 5. 여백 · 폭

- 본문 최대 폭: 가운데 정렬, 좌우 여백 충분히 (모바일에서도 답답하지 않음)
- 섹션 간 **세로 간격이 큼** (히어로 ↔ CTA ↔ 퀵메뉴가 붙어 보이지 않음)
- 히어로 안: 일러스트/사진과 숫자·카피 사이 **숨 쉴 공간**
- 헤더는 얇고, 본문 시작은 바로 큰 비주얼

우리 `--max: 72rem`은 비슷하거나 약간 넓음. 문제는 폭보다 **카드 radius·이미지 중복**.

---

## 6. 타이포 · 색

- 본문: Noto Sans KR 계열 산세리프
- 강조: 굵기·큰 숫자(통계)로 계층
- 색: 흰 + 크림 히어로 + **한 가지 파랑** CTA. 보라 글로우·다층 그림자 없음

---

## 7. 공명교에 바로 적용할 규칙

1. **이미지 1장 = 1곳** (히어로 슬라이드끼리도 서로 다른 컷)  
2. 퀵/경로 카드에는 **사진 넣지 않음** (라인 아이콘 또는 텍스트만)  
3. 둥글기: 히어로 **0**, 카드·CTA **6–12px**, pill(`999px`)은 도트·작은 버튼만  
4. 사진 본진은 `합명 사진`·`행사사진`·스테이션 체험에만  
5. 연혁·교리 페이지는 **글 + 소제목 + 여백**으로 가독성 (장식 사진 최소화)
