# 공명 스테이션 앱

2035 Micro-Care 영적 인프라 프로토타입.  
표어: 「듣고 있습니다」 · 「말씀해 주십시오」

## 실행 (가장 간단)

1. `app\실행.bat` 더블클릭  
   (또는 프로젝트 루트 `실행.bat`)
2. 브라우저가 `http://localhost:5173` 으로 열림  
3. 종료: 검은 창에서 `Ctrl+C`

Node.js가 필요합니다. https://nodejs.org

## 수동 실행

```bash
cd app
npm install
npm run dev
```

- 화면: http://localhost:5173  
- API: http://localhost:8787  
- 기본: `AI_DISABLED=1` — API 키 없이 demo/템플릿으로 바로 시연 (토큰 미사용).
- (선택) AI 쓰려면 `.env`에 `GROQ_API_KEY` 또는 Ollama, 그리고 `AI_DISABLED=0`.

## 폴더

```
app/
  실행.bat
  client/     화면 (Vite) — index, styles, wave, main…
  server/     API (Express) — 경청·위로·위험 연계
  data/       로컬 저장
  scripts/    점검용
```

## 디자인 요지

- 흰 배경 + 앰버 파동 (PPT 톤과 맞춤)
- 첫 화면은 의례 입구: CTA 하나, 계정·전통은 보조
- AI = Bridge (신·사제 UI 없음)

### 카피 원칙 (판정 UI)

- 공명 경험의 진위·크기를 **점수·등급·인증**하지 않는다.
- 스테이션은 종교 **공명**의 실천 자리(빈 방)이며, 종교 자체가 아니다.
- 「기본적 가치」와 「흔적·영향·성취·유용성」을 섞어 말하지 않는다.
- 삶의 가치를 **판결**하지 않는다. 「의미를 찾아라」「목적이 없으니 무가치하다」로 닫지 않는다.
