# 인간과 종교 — 공명교(共鳴敎)

2035년 조별 과제.  
**공명교**는 모든 인간의 영혼이 신적 존재인 **원음(原音)**에서 비롯되었다고 믿는 종교다.

표어:

> 우리는 서로 다른 울림으로 태어나, 서로를 울리고, 하나의 원음으로 돌아간다.

## 핵심 한 줄

인간은 하나의 **근원파**를 품고 태어나, 여러 생에 걸쳐 **공명**하여 **명흔**을 쌓고, **완명**하면 **귀원**한다.  
악행은 **절명**이며, 반복되면 **탁명**하여 완명에서 멀어진다 — 점수와 지옥이 아니다.
