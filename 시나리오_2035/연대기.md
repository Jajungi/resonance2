# 연대기 — 2028→2035

기원 상세: [`기원_대침묵과충격파.md`](기원_대침묵과충격파.md)

| 시기 | 감각·결과 | 종교 |
|------|-----------|------|
| **〜2027** | (참고) | 소수. 시대종교 아님 |
| **2028** | 불이 왔다. 연락·물자 흔들림 | 거점=생존 자리. 신앙 이전의 쓸모 |
| **2029 대침묵** | 통신 증발. 생사 불명. 배급·단절 | 벽·파동 → **공명·명흔**. 합명=추모·소식. 스테이션 씨앗 |
| **2030 충격파** | 몸의 강제 진동. 가짜 합일 오독은 짧게 소멸 | **절명·탁명** 교정. **영명**. 공명교만 남음 |
| **2031–32** | 멈춤. 실종·이산. 부유하지 않음 | 합명일=달력. 속죄=삶. 스테이션 복제 |
| **2033–35** | 강제 파동을 다시 원하지 않음 | 일상어화. 스테이션에 감 |

2029: *신을 믿어서가 아니라 장례를 못 치러서.*  
2035: *대침묵과 충격파를 설명해 준 이름이 공명교다.*
