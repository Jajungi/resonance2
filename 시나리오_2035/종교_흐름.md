# 종교 흐름 — 개전 이후

기원: [`기원_대침묵과충격파.md`](기원_대침묵과충격파.md)

---

**〜2027** 소수. 시대종교 아님.

**2028** 거점 = 생존(연락·자리). 신앙 이전의 쓸모.

**2029 대침묵** 명흔이 시대어. 합명 = 시신 없이 추모·소식. 벽 메모 → 스테이션 씨앗.

**2030 충격파** 강제 파동≠공명 (절명·탁명). 오독은 교파 없이 소멸. **공명교만** 체계로 남음. 영명=흡수 거부.

**2031–32** 합명일=민간 달력. 속죄=삶. 스테이션 복제.

**2033–35** 절명·명흔·탁명이 일상어. 주류.

```
소수 → 생존 거점 → 대침묵(명흔·합명) → 충격파(교정) → 달력 → 주류
```

두지 않음: 이단 대립사 · 교주 · 헌금 구원 · 국가종교화 · 독음 · 환생 처벌
